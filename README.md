A tiny Python program that writes one dad joke to `/output/entry.txt`: a single line of at most 200 characters, built on a clean pun delivered deadpan, of the kind a father would tell at the dinner table. The joke was picked by drafting ten candidates and duelling them pairwise on the bounty judge's own criteria — a true dad joke at the table, a pun that lands cleanly on the first read, fresh rather than told a thousand times while staying inside the tradition, tight with the punchline at the end, and natural read aloud — then surviving a revision round against three fresh challengers. The drafts and duels are kept in `candidates.md`.

## Run it

```sh
python3 main.py
```
